## **Cómo funciona SAP SuccessFactors en la nube**
**SAP SuccessFactors** es el líder en la nube básicamente porque nos permite administrar todos los datos de los empleados de forma centralizada desde cualquier momento y cualquier lugar a partir de modelos de datos. Estos modelos de datos se utilizan para configurar el sistema de tal manera que satisfaga los requisitos de tu empresa y se definen durante el proceso de implementación del sistema.

Los modelos de datos disponibles en **SAP SuccessFactors**son:

### **Modelo de datos corporativos**

Es donde se configura la organización, el salario y la estructura de trabajo de una empresa.

### **Modelo de datos de sucesión**

Aquí es donde se configura la estructura de datos que se relaciona con las personas que trabajan en una empresa.

### **Modelo de datos corporativos específicos del país**

Este modelo es donde se configura campos que son específicos de un solo país. El modelo de datos corporativos específicos del país es relevante para aquellas empresas que tienen ubicaciones en más de un país, por ejemplo, para definir los campos de direcciones corporativas para cada ubicación.

![experiencia de Onboarding_sabiasque-1](https://blog.peoplenext.com/imagenes_hubspot/experiencia-de-Onboarding_sabiasque-1-2.png)

### **Modelo de datos de sucesión específico del país**

Aquí es donde se configura formatos y campos internacionales, por ejemplo, para direcciones y ID nacionales. Se podría configurar este modelo de datos incluso si una empresa opera en un solo país, ya que sus empleados podrían vivir o venir del extranjero.

Una vez entendidos los distintos modelos de datos que pueden configurarse en el software de recursos humanos de SAP es importante platicar un poco sobre sus distintos módulos. SuccessFactors es una solución compuesta por diferentes módulos que cubren cada uno de los procesos de recursos humanos: [reclutamiento](https://peoplenext.com.mx/software-de-reclutamiento-y-seleccion-del-personal.htm), [contratación](https://peoplenext.com.mx/software-de-reclutamiento-y-seleccion-del-personal.htm), [onboarding](https://peoplenext.com.mx/onboarding-software.htm), [capacitación](https://peoplenext.com.mx/software-de-e-learning-lms.htm), etc. Cada módulo puede adquirirse de forma independiente, lo que significa que**tú mismo puedes elegir por dónde empezar según las necesidades de tu empresa.**

Evidentemente, estos módulos se integran entre sí para dar lugar a una única fuente de la verdad. Todos los procesos y datos de tu departamento de recursos humanos en un mismo lugar, ¿Genial no?
